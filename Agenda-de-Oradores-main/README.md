favicon# Agenda de Oradores

Aplicativo para gestão de discursos públicos e intercâmbio de oradores entre congregações.
8
## 🚀 Funções Principais

- **Calendário Inteligente**: Visão unificada de discursos e eventos com trava automática de conflitos.
- **Agendamento de Visitas**: Fluxo simplificado para agendar oradores visitantes ou saídas.
- **Gestão de Oradores**: Cadastro de contatos e repertório individual de temas.
- **Histórico de Temas**: Rastreamento de uso de cada tema para garantir variedade no alimento espiritual.
- **Importação JW.org**: Cadastro rápido de congregações via texto copiado do site oficial.
- **Sistema de Ajudantes**: Gestão colaborativa via convites de acesso único.
- **Comunicação via WhatsApp**: Notificações automáticas formatadas para oradores e coordenadores.
- **Mobile First (PWA)**: Interface otimizada para celulares e instalável como app nativo.

## 🛠️ Tecnologias
- Next.js 15
- Firebase (Auth & Firestore)
- Tailwind CSS
- ShadCN UI
