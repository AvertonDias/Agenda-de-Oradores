# **App Name**: Agenda de oradores

## Core Features:

- Cadastro de Congregação: Permitir que as congregações anfitriãs cadastrem informações como endereço, nome e contato do coordenador.
- Agendamento de Discursos: Interface para agendar discursos, selecionando cidade, orador e tema do discurso.
- Calendário de Discursos: Visualização em calendário dos discursos agendados, mostrando dia, horário, tema e congregação.
- Notificações de Agendamento: Enviar notificações aos oradores sobre os agendamentos confirmados.
- Gerenciamento de Oradores: Banco de dados de oradores com nome, telefone e temas disponíveis.

## Style Guidelines:

- Cor primária: Azul claro (#ADD8E6), evocando confiança e organização.
- Cor de fundo: Branco suave (#F8F8FF), para um visual limpo e profissional.
- Cor de destaque: Verde (#90EE90) para ações importantes, como agendar e confirmar.
- Fonte para títulos e corpo do texto: 'PT Sans', uma fonte sans-serif que oferece um equilíbrio entre modernidade e legibilidade, adequada tanto para títulos quanto para textos.
- Utilizar ícones claros e intuitivos para representar as diferentes funcionalidades, como agendar, visualizar e configurar.
- Layout responsivo para garantir a usabilidade em diferentes dispositivos (desktops, tablets e smartphones).
- Transições suaves e animações sutis para melhorar a experiência do usuário durante a navegação e o agendamento.
